# 坦克大战 · Tank Battle

一个用原生 HTML5 Canvas 写的经典坦克大战小游戏，零依赖、单文件，双击即玩。

## 在线试玩

打开 GitHub Pages 地址即可游玩（若已开启）：

```
https://<你的用户名>.github.io/<仓库名>/
```

## 本地运行

仓库里只有 `index.html` 一个文件，没有任何构建步骤：

- 直接双击 `index.html` 用浏览器打开；
- 或者起一个静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 操作方式

| 按键 | 作用 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动坦克 |
| `空格` / `J` | 开火 |
| `P` / `Esc` | 暂停 / 继续 |
| `Enter` | 开始游戏、进入下一关 |

## 玩法

守住画面底部的**基地**（金色盾徽），消灭每一波敌方坦克。基地被击毁或生命耗尽即游戏结束。

- 地图上有**砖墙**（可打穿）、**钢墙**（普通子弹打不动）、**河流**（坦克过不去、子弹能飞过）和**树林**（坦克藏在下面看不见）。
- 击杀身上带金色标记的敌军会掉落**道具**：

| 道具 | 效果 |
| --- | --- |
| ★ | 火力升级，满级后子弹可击穿钢墙 |
| ♥ | 生命 +1 |
| ◎ | 10 秒无敌护盾 |
| ✹ | 全屏清场，直接消灭当前所有敌军 |
| ⏱ | 冻结敌军 8 秒 |
| ⛏ | 基地周围的砖墙临时变成钢墙，持续 15 秒 |

- 关卡会不断推进，敌军数量、种类和速度都会逐关提升。
- 注意：自己的子弹也会打坏基地，别朝老家开炮。

## 技术说明

- 纯原生 JavaScript，无框架、无依赖、无构建。
- 单文件 `index.html`，内联 CSS 与 JS。
- 全部图形由 Canvas 2D 程序化绘制，没有图片资源。
- 音效由 WebAudio 实时合成，没有音频文件。
- 适配高分屏（devicePixelRatio），窗口失焦自动暂停。
